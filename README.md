# Plant Counter (Подсчет комнатных растений)

Проект по разработке системы искусственного интеллекта для автоматического подсчета комнатных растений на фотографиях с использованием YOLOv8 и Streamlit.

## Технологии
- Python 3.10+
- Ultralytics YOLOv8
- Streamlit
- OpenCV
